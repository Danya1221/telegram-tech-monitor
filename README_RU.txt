QUANTUM / TECH MONITOR — CLEAN BUILD

Это чистая актуальная сборка.

Файлы:
- main.py — бот + мониторинг
- requirements.txt — Python зависимости
- railway.json — Railway запускает python main.py
- Procfile — запасной start command
- .env.example — список переменных без секретов

ВАЖНО ПРИ ПЕРЕЗАЛИВКЕ
1. Не запускай одновременно старый и новый Service.
2. Лучше создать НОВЫЙ Railway Service/Project из этой папки.
3. Подключи PostgreSQL.
4. Добавь Variables:
   API_ID
   API_HASH
   BOT_TOKEN
   DATABASE_URL
   ADMIN_ID
   ANALYTICS_TZ
5. Deploy.
6. Подключи Telegram-аккаунт(ы) через /login.
7. Выбери чаты заново при необходимости.
8. Добавь запросы заново.

АКТИВНЫЙ СПИСОК ЗАПРОСОВ
Сборка использует только новую таблицу:
monitor_queries_v2

Старая таблица queries не участвует в поиске.

ЗАПРОСЫ
- список разбит по 8 позиций на страницу;
- удаление тоже постраничное;
- каждая кнопка удаления привязана к конкретному ID;
- после удаления страница перечитывается из PostgreSQL;
- пустой список = монитор ничего не матчится по запросам.

MATCHING
В сборке уже есть исправления:
- PlayStation 5 Pro не ловит MacBook Pro;
- Ray-Ban Meta не ловит Meta Quest / sport band / Blu-Ray;
- S26 не ловит S26 Ultra / Plus / Edge;
- S26 Black выбирает только подходящую строку каталога;
- iPhone 17 не ловит iPhone 17 Pro;
- цвета / память / eSIM / модификации модели проверяются строго;
- опечатки и транслитерация по-прежнему поддерживаются.

УВЕДОМЛЕНИЯ
Задержка: 15 секунд.
Перед отправкой запрос повторно проверяется в базе.
Если за время задержки запрос удалён, уведомление отменяется.

АНТИДУБЛЬ
Одинаковый продавец + одинаковый нормализованный запрос
в нескольких чатах подряд подавляется на 120 секунд.

ПРОВЕРКА
Скрытая команда:
/querycount
показывает число активных запросов в monitor_queries_v2.
